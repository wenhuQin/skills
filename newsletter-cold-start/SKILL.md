# 资讯源冷启动订阅

## 目标
精选一批免费 AI/财经通讯，用专属邮箱逐个订阅，处理确认信与验证链接，并留下成功/失败清单。

## 前提
- 专属邮箱已开启
- 用户已同意用助手邮箱做注册/订阅；若未知，先问一次（静默 routine 里不要擅自问或替签）

## 步骤
1. 整理精选免费通讯清单（名称、订阅页或订阅方式、类别：AI 或财经）。
2. 用约定的专属邮箱，按清单逐个提交订阅（避免一次开太多并行导致漏确认）。
3. 查收该邮箱的欢迎信/确认信；对需要验证的，按站点正常流程处理确认（不要点营销卸载以外的陌生链接）。
4. 记录每一项：成功 / 失败 / 待确认，以及失败原因（需登录、地区限制、人机验证未过等）。
5. 把清单结果回传给用户；对「待确认」项说明还差哪一步。若此处无法完成确认点击，如实说明哪些源会一直收不到正文。

## 注意
- 只用用户已批准的专属邮箱，不用个人常用邮箱，除非用户明确要求。
- 不注册需要密码的账号，除非用户明确要求并走安全表单。
- 不顺带勾选无关营销包。
- 具体邮箱地址与清单内容由调用方提供，不要写死在本技能。
